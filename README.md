# IoT Projects

A collection of my IoT and embedded projects, mostly built on the ESP32 with the Arduino IoT Cloud.

## Projects

| Project | Description | Board |
| --- | --- | --- |
| [Smart Irrigation Monitoring and Controlling System](iot-irrigation-motor-control-system/) | Real-time monitoring of soil moisture, temperature and humidity, with remote control of the water pump and servo valve. | ESP32 |

```
    ├── thingProperties.h

    ├── sketch.json
    ├── images/
    └── README.md
```
